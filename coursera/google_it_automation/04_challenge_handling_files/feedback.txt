One question asked about eliminating "an extra line" (singular) in the output generated from reading a file line by line. This is an ambiguous question, as it requests the "content of each line" to be preserved, while eliminating "these extra blank lines" (plural). It lists the correct answer as skipping lines containing only whitespace, which is a valid solution for one interpretation of the problem. However, in the practice leading up to this, a common occurrence while printing a file line-by-line was an extra blank line appearing after each printed line, because the built-in`print()` function automatically adds a line ending, and the suggested file reading technique of iterating using `for line in fileobj:` on a file object includes the line ending. The extra lines produced in this situation would be resolved by the other answer: Change the print function call to `print(line, end="")`.
