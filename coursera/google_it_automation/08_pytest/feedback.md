> Pytest is a user-friendly testing framework for developers writing code in Python to focus on creating simple and clear tests. Pytests are written using the `assert()` operation to compare actual values with expected results.

`assert` is a statement, not a function, and things like `assert(thing is not None)` do technically work, but are wildly misleading.

Also, I've never seen documentation referring to tests written for use with pytest referred to as "Pytests".

Lastly, fixtures are great and really important, but not necessary for most beginning developers to learn about. And Python's decorator syntax hasn't been covered yet.
